Introducción

A continuación se presenta un consolidado de las licencias de software utilizadas en las distintas facultades de UNITEC y CEUTEC, con el objetivo de proporcionar una visión clara de la inversión, alcance y uso de estas herramientas tecnológicas. Este análisis busca evaluar la alineación del software con las necesidades académicas, identificar oportunidades de optimización y guiar la toma de decisiones estratégicas para futuras negociaciones y adquisiciones.

Conclusiones y Próximos Pasos

Conclusiones Clave

  • La inversión en software es significativa y está fuertemente alineada con áreas estratégicas (Salud y Diseño).
  • El modelo de licencia campus-wide (MATHWORKS) demuestra ser el más eficiente en costo-beneficio.
  • Existen oportunidades para evaluar la utilización real de licencias por usuario (Adobe, SPSS) y buscar sinergias.
  • La gestión y negociación centralizada son clave para obtener mejores condiciones.

Recomendaciones ➡️

  • Auditoría de Uso: Realizar un análisis del uso real de licencias de Adobe y SPSS para adecuar el número de licencias.
  • Evaluación de Consolidación: Crear un comité para evaluar la posible consolidación de herramientas estadísticas (ej. Minitab vs. SPSS).
  • Centralizar Negociaciones: Continuar negociando renovaciones de forma centralizada y buscar acuerdos multianuales.
  • Fomentar Alianzas Educativas: Crear un programa proactivo para buscar y gestionar más convenios de software sin costo.
